# Xenon Telegram Bot

This bot lets users submit IFC files directly in Telegram and receive the same ventilation report generated by the Xenon backend.

## What it does

- Accepts `.ifc` file uploads from Telegram
- Calls Xenon backend `POST /analyze` with `send_email=false`
- Returns report summary and full text report in chat
- Returns AI suggestions from backend response
- Includes `/health` command to verify backend connectivity

## Prerequisites

- Python 3.10+
- Running Xenon backend API (`xenon-backend/api.py`)
- Telegram bot token from `@BotFather`

## Setup

1. Go to the bot folder:

```powershell
cd xenon-bot
```

2. Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

3. Create env file:

```powershell
copy .env.example .env
```

4. Edit `.env` and set:
- `TELEGRAM_BOT_TOKEN`
- `BACKEND_API_URL` (default `http://127.0.0.1:8000`)

## Run locally

1. Start backend in a separate terminal:

```powershell
cd xenon-backend
python -m uvicorn api:app --host 0.0.0.0 --port 8000 --reload
```

2. Start the Telegram bot:

```powershell
cd xenon-bot
python bot.py
```

3. In Telegram:
- Open your bot chat
- Run `/start`
- Upload an IFC file as a document
- Receive PASS/FAIL report + suggestions

## Notes

- This bot currently does not provide 3D preview (as requested).
- File size is limited by `MAX_FILE_SIZE_MB` and Telegram upload constraints.
- The bot reuses backend logic so report behavior stays aligned with the web app.
